# Capstone Project Rules & Environment

## Environment Isolation
- All Python dependencies for this project MUST reside in the dedicated Conda environment:
  - **Environment Name**: `capstone_voice`
  - **Location**: `C:\Users\shive\.conda\envs\capstone_voice`
  - **Python Binary**: `C:\Users\shive\.conda\envs\capstone_voice\python.exe`
  - **Pip Binary**: `C:\Users\shive\.conda\envs\capstone_voice\Scripts\pip.exe`
- NEVER install packages into the global / main Python environment.
- Always execute tests, scripts, and server commands using the `capstone_voice` environment.
