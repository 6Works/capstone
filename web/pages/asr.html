Log-Mel Spectrogram Feature Extraction

Raw waveform samples $x[n]$ are non-stationary. To extract speech phonemes, the input is converted into time-frequency representation via Short-Time Fourier Transform (STFT):

Mel Scale Frequency Warp:
m = 2595 · log10(1 + f / 700)

Human hearing exhibits non-linear frequency resolution (high sensitivity below 1 kHz, logarithmic spacing above). Applying 80 triangular Mel filterbanks aligns feature density with human auditory perception.

Standard Feature Window Specifications:
  • Window Size: 25 milliseconds (400 samples at 16 kHz) with Hann tapering.
  • Hop Length: 10 milliseconds (160 samples), giving 100 frames/sec.
  • Filterbanks: 80 mel-frequency channels.
  • Dynamic Range Compression: Logarithmic amplitude scaling $\log(E + \epsilon)$.

Both models implement IASRService.transcribe() returning an identical ASRResult DTO. The orchestrator never knows which engine performed the inference.

IASRService Interface & Data Transfer Object 

class IASRService(ABC):
    @abstractmethod
    def transcribe(self, payload: AudioPayload) -> ASRResult:
        """Transcribes incoming audio payload into normalized text."""
        pass

class ASRResult(BaseModel):
    transcript: str
    confidence: float = 1.0
    detected_language: str = "en"
    duration_sec: float = 0.0
    provider: str = "google"
    metadata: Dict[str, Any] = Field(default_factory=dict)
