Physics of Speech Sampling & The Nyquist Theorem

Human speech is generated by air expelled from the lungs, modulated by vocal cords (producing fundamental frequency $F_0 \approx 85 - 255 \text{ Hz}$), and filtered through the vocal tract (tongue, lips, pharynx) to create formants ($F_1, F_2, F_3$).

Nyquist-Shannon Theorem:
f_sample ≥ 2 · f_max

For intelligibility in acoustic speech recognition (ASR), frequencies above 8,000 Hz provide diminishing returns. Therefore, a 16 kHz sampling rate perfectly captures all speech spectral cues without aliasing distortion.

Dynamic Range & Quantization Noise

Signal-to-Quantization-Noise Ratio (SQNR):
SQNR ≈ 6.02 · N + 1.76 dB ≈ 98.08 dB (for N = 16 bits)

A 98 dB dynamic range easily handles everything from soft whispers (30 dB SPL) to loud shouts (100 dB SPL) without digital clipping.

Adheres to the Interface Segregation Principle (ISP). Any input source (microphone, file upload, WebRTC stream, synthetic generator) implements this exact interface: 

class IAudioInputService(ABC):
    @abstractmethod
    def capture(self, **kwargs) -> AudioPayload:
        """Captures acoustic signal and returns normalized payload."""
        pass

class AudioPayload(BaseModel):
    file_path: Optional[str] = None
    raw_bytes: Optional[bytes] = None
    sample_rate: int = 16000
    channels: int = 1
    sample_width: int = 2  # 16-bit
    format: str = "wav"
    duration_sec: float = 0.0
    source_type: str = "microphone"
