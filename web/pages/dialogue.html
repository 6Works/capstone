Finite State Machine (FSM) State Architecture

S0
INITIAL
Awaiting first session input or trigger.
S1
IN_CONVERSATION
Active multi-turn conversational exchange.
S2
EXECUTING_TOOL
Executing math, clock, or knowledge tool.
S3
CLOSING
User farewell; session teardown.
Mathematical Transition Function:
S_{t+1} = δ(S_t, Intent_t, Context_t)

Guarantees conversational integrity. If the user requests a calculation while in IN_CONVERSATION, state temporarily transitions to EXECUTING_TOOL to resolve the operand result before returning control to conversational synthesis.

Hierarchical Memory Separation

In compliance with the Single Responsibility Principle (SRP), memory storage is decoupled from dialogue policy via the IMemoryStore interface:

Tier 1: Short-Term Working Buffer

Sliding FIFO queue of the last $K$ turns (default $K=10$). Captures immediate conversational flow and anaphoric pronoun references ("it", "they", "that").

Tier 2: Slot & Entity Context Store

Key-value dictionary accumulating user variables throughout the session (e.g. user_name, preferred_voice, last_calculation).

Tier 3: Long-Term Vector Memory Future Upgrade

Embedding-based persistent store (ChromaDB / Pinecone). Performs approximate nearest-neighbor (ANN) retrieval for cross-session episodic memory.

IDialogueService & IMemoryStore Contracts 

class IDialogueService(ABC):
    @abstractmethod
    def process_turn(self, nlp_result: NLPResult) -> DialogueTurnResult:
        """Evaluates policy, updates memory, and synthesizes response."""
        pass

    @abstractmethod
    def reset(self) -> None:
        """Clears working memory and resets FSM to INITIAL."""
        pass

class DialogueTurnResult(BaseModel):
    user_text: str
    bot_response: str
    intent: str
    state_after: str
    tool_executed: Optional[str] = None
    tool_result: Optional[str] = None
    turn_index: int = 0
